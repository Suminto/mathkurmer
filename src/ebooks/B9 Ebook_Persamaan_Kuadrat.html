Bagian A

Pengertian Persamaan Kuadrat

Persamaan kuadrat adalah persamaan polinomial berderajat dua dengan satu variabel. Persamaan ini memiliki peran sangat penting dalam matematika karena banyak fenomena alam dan rekayasa yang dapat dimodelkan dengan bentuknya.

📌 Definisi

Persamaan kuadrat adalah persamaan yang berbentuk:

\[ ax^2 + bx + c = 0 \]

di mana \(a, b, c \in \mathbb{R}\), \(a \neq 0\), dan \(x\) adalah variabel.

Koefisien & Konstanta

Dalam persamaan \(ax^2 + bx + c = 0\):

  • \(a\) = koefisien dari \(x^2\) (tidak boleh nol)
  • \(b\) = koefisien dari \(x\)
  • \(c\) = konstanta (suku bebas)
✦ Contoh — Identifikasi Koefisien

Persamaan \(3x^2 - 5x + 2 = 0\):

  • \(a = 3\), \(b = -5\), \(c = 2\)

Persamaan \(x^2 - 9 = 0\):

  • \(a = 1\), \(b = 0\), \(c = -9\)

Persamaan \(2x^2 + 4x = 0\):

  • \(a = 2\), \(b = 4\), \(c = 0\)
💡 Tips Identifikasi

Pastikan persamaan sudah dalam bentuk standar \(ax^2 + bx + c = 0\) sebelum mengidentifikasi koefisien. Pindahkan semua suku ke ruas kiri jika perlu.

Menyelesaikan Persamaan Kuadrat

Ada tiga metode utama menyelesaikan persamaan kuadrat. Pilihan metode bergantung pada bentuk persamaannya.

Video Pembelajaran — Persamaan Kuadrat

B.1 — Dengan Memfaktorkan

Metode ini berlaku ketika persamaan kuadrat dapat ditulis sebagai hasil kali dua faktor linear.

📐 Prinsip

Jika \(ax^2 + bx + c = (px + q)(rx + s) = 0\), maka:

\[ px + q = 0 \quad \text{atau} \quad rx + s = 0 \]

Langkah-langkah Memfaktorkan (a = 1):

  1. Cari dua bilangan \(p\) dan \(q\) sehingga \(p \cdot q = c\) dan \(p + q = b\)
  2. Faktorkan menjadi \((x + p)(x + q) = 0\)
  3. Selesaikan setiap faktor
✦ Contoh 1 — Memfaktorkan sederhana

Selesaikan: \(x^2 - 5x + 6 = 0\)

1
Cari dua bilangan dengan hasil kali \(= 6\) dan jumlah \(= -5\).
Bilangan tersebut: \(-2\) dan \(-3\), karena \((-2)(-3)=6\) dan \(-2+(-3)=-5\).
2
Faktorkan: \((x - 2)(x - 3) = 0\)
3
\(x - 2 = 0 \Rightarrow x = 2\)
\(x - 3 = 0 \Rightarrow x = 3\)
✅ Himpunan Penyelesaian

\(HP = \{2, 3\}\)

✦ Contoh 2 — Koefisien a ≠ 1

Selesaikan: \(2x^2 + 5x - 3 = 0\)

1
Kalikan \(a \cdot c = 2 \cdot (-3) = -6\). Cari dua bilangan dengan hasil kali \(-6\) dan jumlah \(5\): yaitu \(6\) dan \(-1\).
2
Urai suku tengah: \(2x^2 + 6x - x - 3 = 0\)
3
Kelompokkan: \(2x(x + 3) - 1(x + 3) = 0\)
Faktorkan: \((2x - 1)(x + 3) = 0\)
4
\(x = \dfrac{1}{2}\) atau \(x = -3\)
✅ Himpunan Penyelesaian

\(HP = \left\{\dfrac{1}{2},\ -3\right\}\)

B.2 — Dengan Melengkapkan Kuadrat Sempurna

Metode ini mengubah persamaan kuadrat menjadi bentuk \((x + p)^2 = q\) sehingga akar-akarnya mudah dicari.

📐 Langkah Umum (untuk a = 1)
  1. Pindahkan konstanta ke ruas kanan: \(x^2 + bx = -c\)
  2. Tambah kedua ruas dengan \(\left(\dfrac{b}{2}\right)^2\)
  3. Ruas kiri menjadi kuadrat sempurna
  4. Tarik akar kedua ruas
✦ Contoh — Melengkapkan Kuadrat Sempurna

Selesaikan: \(x^2 - 6x + 5 = 0\)

1
Pindahkan konstanta: \(x^2 - 6x = -5\)
2
Tambah kedua ruas dengan \(\left(\dfrac{-6}{2}\right)^2 = 9\): \[x^2 - 6x + 9 = -5 + 9 = 4\]
3
Kuadrat sempurna: \((x - 3)^2 = 4\)
4
\(x - 3 = \pm 2\)
\(x = 3 + 2 = 5\) atau \(x = 3 - 2 = 1\)
✅ Himpunan Penyelesaian

\(HP = \{1, 5\}\)

B.3 — Dengan Menggunakan Rumus ABC

Rumus kuadrat (rumus ABC) adalah metode paling universal — dapat digunakan untuk semua persamaan kuadrat, termasuk yang tidak dapat difaktorkan.

📐 Rumus Kuadrat (Rumus ABC)
\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

Diskriminan (D)

Nilai \(D = b^2 - 4ac\) menentukan jenis akar:

\[ D > 0 \Rightarrow \text{dua akar real berbeda} \\[6pt] D = 0 \Rightarrow \text{dua akar real sama (kembar)} \\[6pt] D < 0 \Rightarrow \text{tidak ada akar real (akar imajiner)} \]
✦ Contoh 1 — D > 0

Selesaikan: \(2x^2 - 7x + 3 = 0\)

1
Identifikasi: \(a=2,\ b=-7,\ c=3\)
2
Hitung diskriminan: \(D = (-7)^2 - 4(2)(3) = 49 - 24 = 25\)
3
\[x = \frac{7 \pm \sqrt{25}}{2 \cdot 2} = \frac{7 \pm 5}{4}\] \(x_1 = \dfrac{7+5}{4} = 3\) atau \(x_2 = \dfrac{7-5}{4} = \dfrac{1}{2}\)
✅ Himpunan Penyelesaian

\(HP = \left\{3,\ \dfrac{1}{2}\right\}\)

✦ Contoh 2 — D = 0 (akar kembar)

Selesaikan: \(x^2 - 6x + 9 = 0\)

1
\(a=1,\ b=-6,\ c=9\)
2
\(D = (-6)^2 - 4(1)(9) = 36 - 36 = 0\)
3
\(x = \dfrac{6 \pm 0}{2} = 3\) (akar kembar)
✅ Himpunan Penyelesaian

\(HP = \{3\}\) (akar ganda)

Bagian C

Menyusun Persamaan Kuadrat

Jika diketahui akar-akar suatu persamaan kuadrat, kita dapat menyusun persamaan tersebut menggunakan hubungan antara akar dan koefisien.

📐 Rumus Menyusun PK dari Akar x₁ dan x₂
\[ x^2 - (x_1 + x_2)x + x_1 \cdot x_2 = 0 \]

Di mana:

  • \(x_1 + x_2 = -\dfrac{b}{a}\) (jumlah akar)
  • \(x_1 \cdot x_2 = \dfrac{c}{a}\) (hasil kali akar)

Hubungan Akar dan Koefisien (Vieta)

\[ \text{Jika } ax^2 + bx + c = 0 \text{ berakar } x_1 \text{ dan } x_2, \text{ maka:}\\[8pt] x_1 + x_2 = -\frac{b}{a} \qquad \text{dan} \qquad x_1 \cdot x_2 = \frac{c}{a} \]
✦ Contoh 1 — Menyusun dari akar yang diketahui

Susun persamaan kuadrat yang akar-akarnya \(x_1 = 3\) dan \(x_2 = -2\).

1
Jumlah akar: \(x_1 + x_2 = 3 + (-2) = 1\)
2
Hasil kali akar: \(x_1 \cdot x_2 = 3 \times (-2) = -6\)
3
Substitusikan: \(x^2 - (1)x + (-6) = 0\)
✅ Persamaan Kuadrat

\(x^2 - x - 6 = 0\)

✦ Contoh 2 — Menyusun dari transformasi akar

Diketahui \(x_1\) dan \(x_2\) adalah akar dari \(x^2 - 3x + 1 = 0\). Susun persamaan baru yang akar-akarnya \(2x_1\) dan \(2x_2\).

1
Dari persamaan asal: \(x_1 + x_2 = 3\) dan \(x_1 x_2 = 1\)
2
Akar baru: \(2x_1 + 2x_2 = 2(x_1+x_2) = 6\)
3
\((2x_1)(2x_2) = 4 \cdot x_1 x_2 = 4\)
4
Persamaan baru: \(x^2 - 6x + 4 = 0\)
✅ Persamaan Kuadrat Baru

\(x^2 - 6x + 4 = 0\)

Bagian D

Penggunaan Persamaan Kuadrat dalam Kehidupan Sehari-hari

Persamaan kuadrat muncul dalam berbagai situasi nyata seperti fisika, arsitektur, ekonomi, dan teknik. Berikut beberapa contoh penerapannya.

Video — Aplikasi Persamaan Kuadrat dalam Kehidupan
✦ Contoh 1 — Masalah Luas Tanah

Sebuah kebun berbentuk persegi panjang memiliki panjang 3 meter lebih dari lebarnya. Jika luas kebun 40 m², tentukan dimensinya!

1
Misalkan lebar = \(x\) meter, maka panjang = \((x + 3)\) meter.
2
Model matematika: \(x(x+3) = 40\)
3
Sederhanakan: \(x^2 + 3x - 40 = 0\)
4
Faktorkan: \((x + 8)(x - 5) = 0\)
5
Solusi: \(x = 5\) (diambil positif) atau \(x = -8\) (tidak valid)
✅ Kesimpulan

Lebar kebun = 5 m, panjang kebun = 8 m

✦ Contoh 2 — Gerak Benda (Fisika)

Sebuah bola dilempar ke atas dengan kecepatan awal 20 m/s dari ketinggian 5 m. Persamaan ketinggian: \(h = -5t^2 + 20t + 5\). Kapan bola menyentuh tanah?

1
Bola menyentuh tanah saat \(h = 0\): \(-5t^2 + 20t + 5 = 0\)
2
Bagi dengan \(-5\): \(t^2 - 4t - 1 = 0\)
3
Gunakan rumus ABC: \(t = \dfrac{4 \pm \sqrt{16+4}}{2} = \dfrac{4 \pm \sqrt{20}}{2} = 2 \pm \sqrt{5}\)
4
Ambil nilai positif: \(t = 2 + \sqrt{5} \approx 4{,}24\) detik
✅ Kesimpulan

Bola menyentuh tanah setelah \(\approx 4{,}24\) detik

💡 Strategi Soal Cerita
  1. Baca soal dengan teliti, tentukan yang dicari
  2. Misalkan variabel untuk besaran yang dicari
  3. Buat model persamaan matematika
  4. Selesaikan persamaan kuadrat
  5. Cek keabsahan solusi (misal: panjang tidak boleh negatif)
